# PinNote Project Instructions

## Project Overview
PinNote is a WPF-based sticky note application for Windows.

## Development Workflow
- **Logging**: All changes, features, and fixes must be recorded in `DEVELOPMENT_LOG.md`. 
- **Documentation**: Ensure `README.md` is updated if there are significant changes to the tech stack or installation process.

## Architecture
- Follow MVVM strictly.
- Keep services decoupled and focused on single responsibilities.
- Use `Newtonsoft.Json` for data persistence.
