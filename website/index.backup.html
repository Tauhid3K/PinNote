No! The downloadable Windows installer (PinNote-Setup-1.0.0.exe) and Linux packages are published as self-contained binaries. The .NET runtime is bundled inside, so it runs out-of-the-box on clean computers with zero prerequisites.

Your notes are 100% private and stored strictly on your local machine in plain, standard JSON format inside your user profile directory. No cloud sync, no tracking, no account required, and no telemetry.

On Wayland (GNOME, KDE Plasma, Sway), compositors handle global hotkeys. PinNote provides a dedicated CLI trigger pinnote --new-note. Simply bind this command to your preferred shortcut (like Super+Shift+N or Ctrl+Alt+N) in your desktop settings.

Yes! PinNote includes full Import and Export functionality in the Dashboard and system tray menu. You can export all your notes into a portable .json or Markdown package, and restore them safely without overwriting existing notes.

PinNote asynchronously checks GitHub Releases on startup. When a newer version is released, an unobtrusive green 🔔 Update v{version} badge appears in the Dashboard header. Clicking it takes you directly to the download page.
